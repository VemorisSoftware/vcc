# /aprender

Aprendizaje: $ARGUMENTS

1. Si está vacío, propón 1 a 3 aprendizajes de esta sesión (cosas no obvias que costó descubrir) y pregunta cuáles guardar.
2. Redáctalo según el skill **memoria-proyecto**: una línea, fecha de hoy, etiqueta.
3. Si ya existe uno parecido, actualízalo en vez de duplicar.
4. Agrégalo a `.vcc/aprendizajes.md` (créalo con el título `# Aprendizajes del proyecto` si no existe).
5. Nunca guardes secretos, tokens ni datos personales.
